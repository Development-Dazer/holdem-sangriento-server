# Changelog

## 2.2.0

- Protocolo WebSocket v2.
- Habilidades, Favor y eventos resueltos por el servidor.
- Token de reconexión de 192 bits y pausa segura de partidas.
- Clasificación de pretemporada con protección contra duplicados.
- Cuota de comandos, ping/pong y cabeceras HTTP de seguridad.
- Pruebas integradas de privacidad, autoridad del host y recuperación de asiento.
